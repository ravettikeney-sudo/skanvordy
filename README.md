# Сканворды каждый день

Восемь видов головоломок: сканворд, классический кроссворд, филворд, кейворд, чайнворд, «Слова из слова», японский кроссворд и судоку. Тематические подборки, сканворд, филворд и судоку дня. Генераторы составляют новые головоломки из базы слов, поэтому они не кончаются.

Открыть: https://ravettikeney-sudo.github.io/skanvordy/
Скачать для Android: https://ravettikeney-sudo.github.io/skanvordy/download/

Новые слова: добавить строки `СЛОВО|вопрос|вопрос` в `words/*.txt` и запустить `python3 tools/build-words.py`.
